About this program

Build a strong foundation for IT support

This guided program brings together the technical foundations and professional habits used by entry-level IT support technicians. Learn in sequence, practice the concepts, and build confidence for real support environments.

Troubleshoot confidently

Use a clear process to identify, isolate, and resolve common hardware, software, and connectivity issues.

Support users effectively

Communicate clearly, document solutions, and provide a reliable customer support experience.

Understand core systems

Work with Windows, networking services, Active Directory, endpoints, and basic security practices.

Prepare for the role

Develop the job-ready knowledge that supports helpdesk and IT support career paths.
